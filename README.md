# 老馬的全能剪輯助手（Laoma Omni Editor）

一個給 **Claude** 用的影片製作技能：丟一支口播影片（或一篇文字稿）進去，自動做出有字幕、有圖解、有配樂的成片。支援 **16:9 長影音**與 **9:16 短影音**。

> 給不熟 Claude 的同事用：Claude 全程代勞，只在幾個關卡問你「有沒有聽錯的字」「圖解可不可以」「草稿可不可以」。

## 特色

- **真人口播 → 成片**：本機語音辨識（GPU）、剪輯表、逐字高亮字幕、人名標、依內容自動挑圖解與動態效果、配樂、品檢、草稿與最終渲染。
- **9:16 直式短影音**：獨立版面，字幕避開平台介面，人像取景可調。
- **AI 旁白**：文字稿 → 雲端 Gemini 逐句配音 → 本機回聽核對、念錯自動重生。初次使用提醒向管理者索取金鑰，並可存進該台電腦、之後不用再輸入。
- **iPhone HDR 自動轉換**：避免渲染慢十幾倍、成片變 HDR。
- **剪輯時在 Chrome 開啟 HyperFrames 預覽**，邊看邊改。
- 動態效果圖鑑 180 種（已移植 114 種、逐像素驗證）、財經／社會／氣象／通用四種主題版型。

## 必備條件

| 項目 | 說明 |
|---|---|
| **Claude 與 Codex 的使用權限** | 兩者都要有。Claude 負責剪輯與判斷；**所有圖片與新主題素材一律由 Codex 生成** |
| Windows 10／11 | 其他作業系統不支援 |
| NVIDIA RTX 4070／5070（12 GB） | 5070 已實機驗證；4070 尚未實機驗證 |
| Google Chrome、FFmpeg、Node.js 18+、HyperFrames、Python 3.11 | 安裝程式會檢查，缺什麼會告訴你 |
| Gemini API 金鑰（選用） | 只有 AI 旁白需要，向管理者索取 |

## 安裝

1. 下載本倉庫（Code → Download ZIP）並解壓縮。
2. **雙擊 `一鍵安裝.cmd`**，或在命令提示字元執行：
   ```
   python -m pip install -r env\requirements.txt
   python -X utf8 env\install.py --permissions
   ```
3. 看環境檢查結果：**✗ 必須補**、**！ 只是提醒**。安裝程式最後會跑一次自我檢測（約 1 分鐘，不連外部服務）。
4. 把 Claude 完全關掉再重開，說：「**老馬的全能剪輯助手，幫我把這支口播做成影片**」。
